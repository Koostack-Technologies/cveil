JavaScript SDK

WASM-powered consent evaluation and masking for Node.js applications, using Node.js WASI for server-side execution.

Note: Requires Node.js 20 or later.

Installation

npm install @cveil/sdk-js

Client Initialization

import { CveilClient } from '@cveil/sdk-js';

const client = await CveilClient.create({
  config: {
    apiBaseUrl: 'https://api.cveil.dev',
    apiToken: 'cveil_your_api_key',
    defaultJurisdiction: 'EU',
    staleMode: 'conservativeMask',  // or 'apiFallback'
    disconnectThresholdMs: 60000,
    decisionCacheMaxSize: 10000,
    decisionCacheTtlMs: 300000,
    dedupWindowSize: 500,
  },
  autoConnect: true,
  graphPageSize: 100,
});
Note: CveilClient.create() is async and returns a Promise. The client loads the WASM module and fetches the initial consent graph on creation.

Configuration Reference

Field Type Default Description
apiBaseUrl string required Cveil API base URL
apiToken string required API token (must start with cveil_)
defaultJurisdiction string required Default jurisdiction
staleMode 'apiFallback' | 'conservativeMask' conservativeMask Behavior when SSE disconnects
disconnectThresholdMs number 60000 Stale threshold in milliseconds
decisionCacheMaxSize number 10000 Max cached decisions
decisionCacheTtlMs number 300000 Cache TTL in milliseconds
dedupWindowSize number 500 Dedup window

Data Masking

Mask objects based on consent decisions. All masking methods are async.

const result = await client.mask('user-123', 'users', {
  email: 'alice@acme.com',
  phone: '555-867-5309',
  ssn: '412-55-6789',
}, 'marketing_emails');

console.log(result.data);
// { email: '****@acme.com', phone: '***', ssn: '***' }
// With jurisdiction override
const euResult = await client.maskWithJurisdiction(
  'user-123', 'users', userData, 'marketing_emails', 'EU'
);
// Batch masking
const results = await client.maskBatch('user-123', 'users', [data1, data2], 'marketing_emails');

Consent Operations

Grant & Revoke

await client.grant({
  subject: 'user-123',
  scope: { categoryName: 'PII', purposeName: 'marketing_emails' },
  expiresAt: '2027-01-01T00:00:00Z',
});

await client.revoke({
  subject: 'user-123',
  scope: { categoryName: 'PII', purposeName: 'marketing_emails' },
});

Evaluate Consent

const response = await client.evaluateConsent('user-123', {
  scopes: [{ categoryName: 'PII', purposeName: 'marketing_emails' }],
});

Governance & Catalogue

All operations mirror the Java SDK but are async. Use await on every call.

// Purposes
await client.registerPurpose({ name: 'marketing_emails', description: 'Promotional emails' });
await client.addPurposePolicy({ purposeName: 'marketing_emails', scopeType: 'CATEGORY', scopeValue: 'PII' });

// Regulations
await client.registerRegulation({ name: 'GDPR', description: 'EU General Data Protection Regulation' });

// Fields
await client.registerField({ entityName: 'users', fieldName: 'email', description: 'User email' });
await client.assignFieldToCategory({ entityName: 'users', fieldName: 'email', categoryName: 'PII' });

Subject Management

await client.registerSubject({ subjectId: 'user-123', description: "Alice's account" });
const subject = await client.getSubject('user-123');
const subjects = await client.listSubjects();
await client.updateSubject('user-123', { description: 'Updated description' });
await client.removeSubject('user-123');

DSAR Compliance

// Export (GDPR Article 20)
const exportData = await client.exportSubjectData('user-123');

// Erasure (GDPR Article 17)
const receipt = await client.deleteSubjectData('user-123');
// receipt: { subjectId, requestId, ledgerEntriesRevoked, cachedKeysDeleted, status, completedAt }

// Irreversible key destruction
await client.shredDsarKey('user-123');
Warning: shredDsarKey is irreversible. Once called, the subject's encryption key is permanently destroyed and their data can never be decrypted.

SDK Lifecycle

const status = await client.status();
// { initialized, connectionState, graphNodes, cachedDecisions }

await client.shutdown();
