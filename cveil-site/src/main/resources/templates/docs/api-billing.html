Billing API

Manage payment methods, subscriptions, invoices, and plan changes via Stripe integration.

Base path: /api/v1/billing

Authentication: Bearer token with appropriate permissions.

Endpoint Summary

GET /api/v1/billing/stripe-config Get Stripe publishable key
POST /api/v1/billing/setup-intent Create SetupIntent
GET /api/v1/billing/payment-methods List payment methods
POST /api/v1/billing/payment-methods/\{paymentMethodId}/attach Attach payment method
DELETE /api/v1/billing/payment-methods/\{paymentMethodId} Detach payment method
PUT /api/v1/billing/payment-methods/\{paymentMethodId}/default Set default payment method
GET /api/v1/billing/invoices List invoices
GET /api/v1/billing/invoices/\{invoiceId} Get invoice details
GET /api/v1/billing/plans List billing plans
GET /api/v1/billing/subscription Get current subscription
POST /api/v1/billing/subscription Create subscription
PUT /api/v1/billing/subscription Change plan
DELETE /api/v1/billing/subscription Cancel subscription

Configuration

GET /api/v1/billing/stripe-config

Returns the Stripe publishable key for initializing Stripe.js on the client side.

Response

{
  "publishableKey": "pk_live_..."
}

Payment Setup

POST /api/v1/billing/setup-intent

Creates a Stripe SetupIntent for securely collecting a payment method. Use the returned clientSecret with Stripe.js to confirm card setup.

Response

{
  "clientSecret": "seti_..._secret_..."
}

Payment Methods

GET /api/v1/billing/payment-methods

Lists all payment methods attached to the tenant's Stripe customer.

Response

[
  {
    "id": "uuid",
    "externalPaymentMethodId": "pm_...",
    "type": "card",
    "cardBrand": "visa",
    "cardLast4": "4242",
    "cardExpMonth": 12,
    "cardExpYear": 2027,
    "isDefault": true,
    "status": "active"
  }
]

POST /api/v1/billing/payment-methods/\{paymentMethodId}/attach

Attaches a Stripe payment method to the tenant's customer account. The paymentMethodId is obtained after completing the SetupIntent flow.

DELETE /api/v1/billing/payment-methods/\{paymentMethodId}

Detaches a payment method from the tenant. Cannot detach the default payment method if an active subscription exists.

PUT /api/v1/billing/payment-methods/\{paymentMethodId}/default

Sets the specified payment method as the default for future invoices and subscription charges.

Invoices

GET /api/v1/billing/invoices

Lists all invoices for the tenant, ordered by most recent first.

Response

[
  {
    "id": "uuid",
    "status": "paid",
    "currency": "usd",
    "amountDue": 4900,
    "total": 4900,
    "hostedInvoiceUrl": "https://...",
    "periodStart": "2026-01-01",
    "periodEnd": "2026-02-01"
  }
]

GET /api/v1/billing/invoices/\{invoiceId}

Returns full invoice details including individual line items, discounts, and tax amounts.

Plans & Subscriptions

GET /api/v1/billing/plans

Lists all available billing plans with pricing tiers, feature limits, and billing intervals.

GET /api/v1/billing/subscription

Returns the tenant's current subscription details including plan, status, and billing period.

Response

{
  "tenantId": "my-app",
  "planTier": "growth",
  "status": "active",
  "billingInterval": "monthly",
  "periodStart": "2026-03-01",
  "periodEnd": "2026-04-01"
}

POST /api/v1/billing/subscription

Creates a new subscription for the tenant. Requires a valid payment method and plan ID.

Request

{
  "planId": "growth",
  "paymentMethodId": "pm_..."
}

PUT /api/v1/billing/subscription

Changes the tenant's subscription to a different plan. Upgrades are applied immediately; downgrades take effect at the end of the current billing period.

Request

{
  "newPlanId": "enterprise"
}

DELETE /api/v1/billing/subscription

Cancels the tenant's subscription. By default, access continues until the end of the current billing period.

Query Parameters

immediate boolean, default false If true, cancels immediately instead of at period end
