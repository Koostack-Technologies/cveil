Banner Config API

Manage consent banner configurations for your websites. Each configuration generates a unique site ID and embed snippet for drop-in consent collection.

Base path: /api/v1/banner

Authentication: Bearer token with appropriate permissions.

Endpoint Summary

GET /api/v1/banner/configs List banner configurations
POST /api/v1/banner/configs Create banner configuration
PUT /api/v1/banner/configs/\{siteId} Update configuration
DELETE /api/v1/banner/configs/\{siteId} Delete configuration
GET /api/v1/banner/configs/\{siteId}/snippet Get embed snippet

Endpoints

GET /api/v1/banner/configs

Lists all banner configurations for the tenant.

Query Parameters

limit integer, default 50 — Maximum results to return

Response

[
  {
    "siteId": "cvs_abc123",
    "siteDomain": "example.com",
    "bannerPosition": "bottom",
    "bannerTheme": "dark",
    "customText": {
      "message": "We use cookies...",
      "acceptButton": "Accept All",
      "rejectButton": "Reject All",
      "preferencesButton": "Manage Preferences"
    },
    "purposes": ["analytics", "marketing", "functional"],
    "createdAt": "..."
  }
]

POST /api/v1/banner/configs

Creates a new banner configuration. Returns the config with a generated siteId that you'll use in the embed snippet.

Request

{
  "siteDomain": "example.com",
  "bannerPosition": "bottom",
  "bannerTheme": "dark",
  "customText": {
    "message": "We use cookies to improve your experience.",
    "acceptButton": "Accept All",
    "rejectButton": "Reject All"
  },
  "purposes": ["analytics", "marketing"]
}

Response

Banner configuration object with generated siteId.

PUT /api/v1/banner/configs/\{siteId}

Updates an existing banner configuration. Changes take effect immediately for new page loads.

DELETE /api/v1/banner/configs/\{siteId}

Deletes a banner configuration. The banner will stop rendering on the associated domain.

GET /api/v1/banner/configs/\{siteId}/snippet

Returns the HTML/JavaScript embed snippet for the specified banner configuration. Copy this snippet into your site's <head> or before the closing </body> tag.

Quick Integration

After creating a banner configuration, add the following snippet to your website. Replace the data-site-id value with your generated site ID.

<script src="https://your-cveil-instance.com/js/cveil-banner.min.js"
        data-site-id="cvs_abc123"></script>

The script automatically:

  • Renders the consent banner based on your configuration
  • Collects user consent preferences
  • Sends consent records to the Cveil API
  • Respects returning visitors' previous choices
Tip: Use the /api/v1/banner/configs/\{siteId}/snippet endpoint to always get the latest recommended snippet for your configuration.
