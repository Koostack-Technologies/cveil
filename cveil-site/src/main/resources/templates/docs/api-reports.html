Reports & Metrics API

Read-only endpoints for consent summaries, audit trails, governance snapshots, and tenant metrics.

Authentication: Bearer token with appropriate permissions.

Reports API

Base path: /api/v1/reports

Method Endpoint Description
GET /api/v1/reports/consent-summary Consent status counts by purpose
GET /api/v1/reports/consent-activity Consent activity timeline (paginated)
GET /api/v1/reports/audit-log Paginated audit trail
GET /api/v1/reports/governance-snapshot Current governance state
GET /api/v1/reports/export/consent-summary Export consent summary as CSV

GET /api/v1/reports/consent-summary

Returns aggregate consent counts broken down by purpose — total grants, total revocations, and per-purpose breakdowns.

Response 200

{
  "totalGrants": 150,
  "totalRevocations": 23,
  "byPurpose": {
    "marketing_emails": {
      "granted": 80,
      "revoked": 10
    },
    "analytics": {
      "granted": 70,
      "revoked": 13
    }
  }
}

GET /api/v1/reports/consent-activity

Returns a paginated timeline of consent events within an optional time range.

Query Parameters

Parameter Type Description
startTimeISO 8601Start of time range
endTimeISO 8601End of time range
limitintegerMax results to return

Response 200

[
  {
    "eventType": "CONSENT_GRANTED",
    "subject": "user-123",
    "purpose": "marketing",
    "timestamp": "2024-01-15T10:30:00Z"
  }
]

GET /api/v1/reports/audit-log

Returns a paginated audit trail of all system events with full payloads.

Query Parameters

Parameter Type Description
startTimeISO 8601Start of time range
endTimeISO 8601End of time range
eventTypestringFilter by event type
limitintegerMax results to return

Response 200

[
  {
    "eventId": "uuid",
    "eventType": "ConsentGranted",
    "aggregateId": "uuid",
    "occurredAt": "2024-01-15T10:30:00Z",
    "payload": {
      "subjectId": "user-123",
      "purposeName": "marketing_emails"
    }
  }
]

GET /api/v1/reports/governance-snapshot

Returns a combined snapshot of the current governance state — all purposes, regulations, and jurisdictions in a single response.

Response 200

{
  "purposes": [...],
  "regulations": [...],
  "jurisdictions": [...]
}

GET /api/v1/reports/export/consent-summary

Export the consent summary as a CSV file stream.

Query Parameters

Parameter Type Description
formatstringExport format (e.g. csv)

Response 200

Returns a text/csv file stream with consent summary data.

Metrics API

Base path: /api/v1/metrics

Method Endpoint Description
GET /api/v1/metrics Get tenant metrics dashboard
GET /api/v1/metrics/summary Get high-level metrics summary

GET /api/v1/metrics

Returns the full tenant metrics dashboard with aggregated counts for requests, consents, and subjects.

Response 200

{
  "totalRequests": 12450,
  "totalConsents": 3200,
  "totalSubjects": 1580,
  "evaluationsToday": 342
}

GET /api/v1/metrics/summary

Returns a high-level summary of tenant metrics for quick dashboard display.

Response 200

{
  "subjects": 1580,
  "purposes": 5,
  "regulations": 2,
  "consentRate": 0.87
}
