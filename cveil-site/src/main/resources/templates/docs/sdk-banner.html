Consent Banner

A lightweight, embeddable widget that collects user consent on any website and syncs it with the Cveil API.

Quick Integration

Add a single script tag to your page — the banner handles the rest:

<script src="https://your-cveil-instance.com/js/cveil-banner.min.js"
        data-site-id="cvs_abc123"></script>
Note: That's it. The banner auto-renders if the user hasn't given consent yet.

Script Attributes

Attribute Required Description
data-site-id Yes Site identifier from Banner Config API (e.g., cvs_abc123)
data-api-base No API base URL (defaults to script origin)
data-subject No Subject ID (generates anonymous ID if not provided)

How It Works

1 Banner loads and reads data-site-id
2 Fetches config from GET /api/v1/public/consent/config/\{siteId}
3 Checks localStorage for existing consent (key: cveil_consent)
4 If no prior consent: renders the consent banner
5 User clicks Accept / Reject / Manage Preferences
6 Consent decisions sent to POST /api/v1/public/consent/grant or /revoke
7 Consent stored in localStorage

JavaScript API (window.CveilBanner)

CveilBanner.show();              // Force-show the banner
CveilBanner.reset();             // Clear stored consent and show banner
CveilBanner.getConsent();        // Get stored consent state
CveilBanner.hasConsent('marketing'); // Check specific purpose

Custom Events

Listen for consent changes on the document object:

document.addEventListener('cveil:consent:accepted', (e) => {
  console.log('All purposes accepted');
});

document.addEventListener('cveil:consent:rejected', (e) => {
  console.log('All purposes rejected');
});

document.addEventListener('cveil:consent:saved', (e) => {
  console.log('Preferences saved:', e.detail.purposes);
});

LocalStorage Structure

The banner persists consent state in two localStorage keys:

{
  "cveil_consent": {
    "siteId": "cvs_abc123",
    "purposes": { "marketing": true, "analytics": false },
    "timestamp": "2026-03-19T10:30:00.000Z"
  },
  "cveil_subject_id": "anon_550e8400-e29b-41d4-..."
}

Banner Configuration

The banner appearance and behavior is configured via the Banner Config API (/api/v1/banner/configs):

Position: top or bottom
Theme: dark or light
Custom text for all buttons and messages
Purpose list with toggle controls

Preferences Modal

When the user clicks "Manage Preferences", a modal opens with per-purpose toggle switches. Users can enable or disable individual purposes before saving their preferences.

Note: The preferences modal respects the purpose list from the Banner Config API. Only purposes configured for the site are shown as toggles.
