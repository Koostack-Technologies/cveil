You focus on building your product. We handle the consent lifecycle, data masking, and regulatory compliance.

27+ Regulations, Zero Config

GDPR, CCPA, HIPAA, COPPA, and 19 US state privacy laws ship pre-configured. Each regulation maps to jurisdictions with purpose-specific masking rules out of the box.

Immutable Consent Ledger

Every grant, revocation, and expiration is permanently recorded in an append-only ledger. When a subject requests deletion, one cryptographic key delete renders all their records unreadable — no audit trail broken.

5 Masking Strategies

RedactLocal, RedactUpToLast4, Hash256, RedactAll, and Plaintext — applied per field or category. Type-safe outputs: strings become ***, numbers become 0, booleans become false.

In-Process WASM Engine

A Rust-compiled WebAssembly engine runs masking inside your application — no network hop required. Sub-millisecond evaluation with an LRU decision cache and conservative deny-by-default fallback.

Multi-Language SDKs

First-class JavaScript, Java, and Rust SDKs that auto-fetch missing consent decisions and stay in sync via real-time SSE cache invalidation. Full REST API with OpenAPI docs for everything else.

Consent Graph Explorer

Visualize and manage purpose → regulation → field relationships in an interactive D3.js graph. Full governance console with entity cataloguing, category management, and policy configuration.
