Public Endpoints

Unauthenticated endpoints designed for client-side consent collection (banner widget) and self-service DSAR submissions.

Note: These endpoints require no authentication. They are CORS-protected and validate the request origin against the configured site domain.

Public Consent API

Base path: /api/v1/public/consent

GET /api/v1/public/consent/config/\{siteId}

Get banner configuration for a site. No auth required. CORS header set to configured siteDomain.

Response

{
  "purposes": ["analytics", "marketing", "functional"],
  "bannerPosition": "bottom",
  "bannerTheme": "dark",
  "customText": {
    "message": "We use cookies...",
    "acceptButton": "Accept All",
    "rejectButton": "Reject All",
    "preferencesButton": "Manage Preferences"
  }
}
POST /api/v1/public/consent/grant

Grant consent from the banner widget. Validates Origin/Referer against the configured siteDomain.

Request

{
  "siteId": "cvs_abc123",
  "subject": "anon_550e8400...",
  "scope": {
    "purposeName": "marketing"
  },
  "expiresAt": "2027-01-01T00:00:00Z"
}

Response

{
  "message": "Consent granted"
}
POST /api/v1/public/consent/revoke

Revoke consent from the banner widget.

Request

{
  "siteId": "cvs_abc123",
  "subject": "anon_550e8400...",
  "scope": {
    "purposeName": "marketing"
  }
}

Response

{
  "message": "Consent revoked"
}

Public DSAR API

Base path: /api/v1/public/dsar

POST /api/v1/public/dsar/submit

Self-service DSAR submission. No authentication required. Rate limited.

Request

{
  "email": "alice@example.com",
  "requestType": "EXPORT",
  "description": "Please export all my data"
}

Response

{
  "message": "DSAR request submitted",
  "requestId": "uuid"
}
Note: Valid requestType values are EXPORT (GDPR Article 20) and ERASURE (GDPR Article 17).
