Quick Start

Go from zero to your first consent record in four steps. You'll create a workspace, generate an API key, install the SDK, and record consent — all in under five minutes.

Prerequisites

Note: You need a Cveil API key to follow this guide. You can obtain one from the Dashboard.

Step 1: Create your Workspace

A workspace is an isolated environment for your application's consent data. Create one from the Dashboard by clicking New Workspace.

Once created, your workspace is assigned an isolated schema and is ready to accept consent data.

Step 2: Create an API Key

Generate a scoped API key for your workspace from the Dashboard under Settings → API Keys. Assign roles like admin or consent-writer to control what the key can access.

Important: The API key is returned only once when created. Copy and store it securely — you will not be able to retrieve it again.

Step 3: Install the SDK

Choose your language and add the Cveil SDK to your project:

Maven:

<dependency>
  <groupId>com.koostack.cveil</groupId>
  <artifactId>cveil-sdk-java</artifactId>
  <version>0.1.0</version>
</dependency>

Gradle:

implementation("com.koostack.cveil:cveil-sdk-java:0.1.0")
npm install @cveil/sdk-js

Step 4: Record your First Consent

Initialize the client, grant consent for a subject, then evaluate it:

import com.koostack.cveil.sdk.CveilClient;
import com.koostack.cveil.sdk.CveilClientOptions;
import com.koostack.cveil.sdk.CveilConfig;

var config = new CveilConfig(
    "https://api.cveil.dev",    // apiBaseUrl
    "cveil_your_api_key",       // apiToken
    "EU",                       // defaultJurisdiction
    "conservativeMask",         // staleMode
    60000L, 10000, 300000L, 500 // thresholds & cache settings
);

var client = CveilClient.create(new CveilClientOptions(config, null, true, 100));

// Grant consent
client.grant(new GrantRequest("user-123",
    new ConsentScope(null, null, "marketing_emails", null, null, null),
    null));

// Evaluate consent
var result = client.evaluateConsent("user-123",
    new EvaluateConsentRequest(List.of(
        new ConsentScope(null, null, "marketing_emails", null, null, null)
    )));
import { CveilClient } from '@cveil/sdk-js';

const client = await CveilClient.create({
  config: {
    apiBaseUrl: 'https://api.cveil.dev',
    apiToken: 'cveil_your_api_key',
    defaultJurisdiction: 'EU',
  }
});

// Grant consent
await client.grant({
  subject: 'user-123',
  scope: { purposeName: 'marketing_emails' },
});

// Evaluate consent
const result = await client.evaluateConsent('user-123', {
  scopes: [{ purposeName: 'marketing_emails' }],
});
