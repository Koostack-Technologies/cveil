Documentation

Everything you need to integrate Cveil into your application — from first API call to production deployment.

Getting Started

1

Create your Workspace

Sign up and create a workspace from the platform dashboard. Each workspace is an isolated tenant with its own database schema and Redis streams.

# Create a workspace via the Platform API

curl -X POST https://api.cveil.dev/api/v1/platform/tenants \

-H "Authorization: Bearer $CVEIL_API_KEY" \

-H "Content-Type: application/json" \

-d '{"{"}"name": "my-app", "region": "us-east-1"{"}"}'

2

Install the SDK

Add the Cveil SDK to your Java project via Maven or Gradle.

<!-- Maven -->

<dependency>

<groupId>dev.cveil</groupId>

<artifactId>cveil-sdk</artifactId>

</dependency>

// Gradle

implementation "dev.cveil:cveil-sdk"

3

Record your first consent

Grant consent for a subject and purpose. The event is immutably recorded in the audit ledger.

import dev.cveil.sdk.Cveil;


var cv = Cveil.builder()

.apiKey("cv_live_sk_...")

.build();


// Grant consent

cv.consent().grant("usr_9982",

"marketing_emails",

Instant.parse("2027-01-01T00:00:00Z"));


// Evaluate consent (sub-millisecond)

boolean allowed = cv.consent().evaluate(

"usr_9982", "marketing_emails");

// → true

API Reference

All endpoints require a Bearer token via the Authorization header. All paths below are relative to the base URL: /api/v1

Consent API

Method Endpoint Description
POST /subjects/consent/grant Grant consent for a single scope
POST /subjects/consent/revoke Revoke consent for a single scope
POST /subjects/consent/grant-all Grant consent for multiple scopes at once
POST /subjects/consent/revoke-all Revoke consent for multiple scopes at once
POST /subjects/consent/evaluate Evaluate whether consent is active for given scopes
GET /subjects/{"{"}id{"}"}/summary List all consent policies for a subject
GET /subjects/{"{"}id{"}"}/history Get current consent state for a subject
GET /subjects/{"{"}id{"}"}/export Export all subject data (GDPR Article 20)
DELETE /subjects/{"{"}id{"}"} Erase all subject data (GDPR Article 17)

Catalogue API

Method Endpoint Description
GET /catalogue/fields List all registered fields
POST /catalogue/fields Register a sensitive field (upsert)
DELETE /catalogue/fields/{"{"}entity{"}"}/{"{"}field{"}"} Remove a registered field
POST /catalogue/fields/categories Assign a category to a field

Legal API

Method Endpoint Description
GET /legal/purposes List all consent purposes
POST /legal/purposes Register a consent purpose (upsert)
POST /legal/purposes/policies Add a policy to a purpose
GET /legal/regulations List all regulations
POST /legal/regulations Register a regulation (upsert)
POST /legal/purposes/regulations Link a purpose to a regulation

Platform API

Method Endpoint Description
POST /platform/tenants Create a new tenant
GET /platform/tenants List all tenants
PUT /platform/tenants/{"{"}id{"}"}/plan Update a tenant's plan
POST /platform/api-keys Create an API key for a tenant
GET /platform/api-keys List API keys for a tenant
DELETE /platform/api-keys/{"{"}prefix{"}"} Revoke an API key
