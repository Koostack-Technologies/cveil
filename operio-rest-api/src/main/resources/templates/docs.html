Everything you need to integrate Operio into your application — from first API call to production deployment.

Getting Started

1

Create your Workspace

Sign up and create a workspace from the platform dashboard. Each workspace is an isolated tenant with its own database schema and Redis streams.

# Create a workspace via the Platform API

curl -X POST https://api.operio.dev/api/v1/platform/tenants \

-H "Authorization: Bearer $OPERIO_API_KEY" \

-H "Content-Type: application/json" \

-d '{"{"}"name": "my-app", "region": "us-east-1"{"}"}'

2

Install the SDK

Add the Operio SDK to your project. We support Node.js, Python, Java, and Go.

# Node.js

npm install @operio/node

# Python

pip install operio

# Java (Maven)

<dependency>

<groupId>dev.operio</groupId>

<artifactId>operio-sdk</artifactId>

</dependency>

# Go

go get github.com/operio/operio-go

3

Record your first consent

API Reference

All endpoints require a Bearer token via the Authorization header. Base URL: https://api.operio.dev/api/v1

Consent API

Method Endpoint Description
POST /consent/grant Grant consent for a subject and purpose
POST /consent/revoke Revoke consent for a subject and purpose
GET /consent/evaluate Evaluate whether consent is active for a subject + purpose
GET /consent/status Get full consent status for a subject across all purposes

Admin API

Method Endpoint Description
GET /admin/fields List all registered sensitive fields
POST /admin/fields Register a new sensitive field
GET /admin/purposes List all registered consent purposes
POST /admin/purposes Register a new consent purpose
POST /admin/categories Create a consent category and link fields

Authentication

Method Endpoint Description
POST /auth/login Authenticate and receive an API token
POST /auth/refresh Refresh an expired access token
